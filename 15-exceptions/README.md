# 15 - Exception Handling

What to do when something goes wrong in your program — instead of crashing, handle the error gracefully.

Topics covered:
- What exceptions are and why they happen
- try-catch — put risky code in try, handle the error in catch
- finally — code that always runs whether an error happened or not
- Checked vs unchecked exceptions
- Multiple catch blocks — handling different error types separately
- Nested try blocks
- throw — manually throwing an exception
- throws — declaring that a method might throw an exception
- Custom exceptions — creating your own exception class.
