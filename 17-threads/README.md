# 17 - Multithreading

Running multiple parts of a program at the same time.

Topics covered:
- What a thread is — a lightweight independent path of execution
- Creating threads using the Thread class
- Creating threads using the Runnable interface
- Thread lifecycle — New → Runnable → Running → Blocked → Dead
- Synchronization — preventing two threads from conflicting over shared data
- Inter-thread communication — wait(), notify(), notifyAll()
- Executor Framework — managing multiple threads efficiently without creating them manually
