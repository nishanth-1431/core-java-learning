# 10 - Polymorphism

One thing, many forms. The same method name can behave differently depending on the object calling it.

Topics covered:
- Compile-time polymorphism — method overloading (decided at compile time)
- Runtime polymorphism — method overriding (decided at runtime)
- How overloading works: same method name, different parameters
- How overriding works: child class redefines a parent class method
- The difference between overloading and overriding
