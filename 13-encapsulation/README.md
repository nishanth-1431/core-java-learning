# 13 - Encapsulation

Wrapping data (variables) and the code that works on it (methods) into a single unit (class), and controlling who can access what.

Topics covered:
- Why you make variables private
- Getters — public methods to read a private variable
- Setters — public methods to update a private variable
- `this` keyword — refers to the current object's fields when there is a naming conflict
- `super` keyword — calls the parent class constructor or method
- `final` keyword — makes a variable, method, or class unchangeable/unextendable
