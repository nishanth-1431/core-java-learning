# 12 - Aggregation

A HAS-A relationship between classes. Instead of one class inheriting from another, one class contains a reference to another.

Topics covered:
- HAS-A relationship — e.g., an Employee HAS-A Address
- Difference between inheritance (IS-A) and aggregation (HAS-A)
- Creating objects inside other objects
- Why aggregation is preferred over inheritance in many real-world designs

Example: instead of Employee extending Address, Employee holds an Address object as a field.
