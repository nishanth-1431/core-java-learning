# 14 - Constructors

Special methods that run automatically when you create an object. Used to set initial values.

Topics covered:
- What a constructor is and how it differs from a regular method
- Default constructor — no parameters, Java provides one if you don't write it
- Parameterized constructor — takes values when the object is created
- Constructor overloading — multiple constructors with different parameters
- Copy constructor — creates a new object by copying values from an existing one
