# 🎯 Number Guessing Game

A simple console-based Number Guessing Game built using Java.

## Features

* Random number generation (1-100)
* 5 attempts per round
* Hints for higher or lower guesses
* Option to continue playing
* Tracks total attempts

## Concepts Used

* Variables
* `if-else`
* `for` loop
* `while` loop
* Boolean variables
* `Math.random()`
* `Scanner`
* `break`

## Future Improvements

* Score tracking
* Difficulty levels
* HTML/CSS/JavaScript interface
