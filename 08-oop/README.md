# 08 - OOP (Object-Oriented Programming)

Everything in Java revolves around classes and objects. This section is the foundation of OOP.

Topics covered:
- What is a class — a blueprint for creating objects
- What is an object — an instance of a class
- Creating objects and accessing fields and methods
- Access modifiers — public, private, protected, default
- Local scope vs global scope (instance variables vs local variables)
