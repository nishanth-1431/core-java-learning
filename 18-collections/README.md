# 18 - Collections

Dynamic data structures built into Java. Unlike arrays, they resize automatically and come with many built-in methods.

Topics covered:
- ArrayList — ordered list, allows duplicates, fast access by index
- LinkedList — ordered list, efficient for adding/removing from middle
- HashSet — unordered collection, no duplicates allowed
- HashMap — stores key-value pairs, fast lookup by key
- Iterators — way to loop through any collection
