# 11 - Abstraction

Hiding the internal details and only showing what is necessary. The user doesn't need to know how it works internally, just what it does.

Topics covered:
- Abstract class — a class that cannot be instantiated directly
- Abstract methods — declared but not implemented in the parent class
- Implementing abstract methods in child classes
- Interface — a fully abstract contract that a class must follow
- Implementing an interface using `implements`
- Difference between abstract class and interface
